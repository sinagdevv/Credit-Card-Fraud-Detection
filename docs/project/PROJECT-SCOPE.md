# SD-008 Project Scope

## Purpose

SD-008 provides a privacy-preserving synthetic credit-card transaction environment for fraud-analysis education and portfolio work in the Eskwelabs Data Innovation Track.

## In scope

- Research-backed synthetic-data specification
- Five-table normalized schema and ERD
- Mathematical distributions, structural equations, and calibration assumptions
- Fraud ground truth, investigation selection, and analyst-observed labels
- Deterministic synthetic-data generation and validation
- Exploratory analysis of synthetic behavior and operational limitations

## Out of scope

- Real customer or bank transaction data
- Production fraud scoring, authorization, or case-management deployment
- Claims that synthetic model prevalence represents Philippine credit-card fraud prevalence
- Real-time integrations or automated enforcement decisions
- Production-grade predictive modeling unless separately approved

## Intended user

The primary user is a fraud analyst investigating transaction patterns, fraud mechanisms, alert selection, and label incompleteness. The work is also designed for academic assessment and a technical portfolio.
